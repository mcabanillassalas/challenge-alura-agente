# ⚠️ Antes de enviar tu Challenge

- Verifica que la URL de tu proyecto sea correcta y que el repositorio esté accesible públicamente.
- El sistema solo acepta URLs de repositorios de GitHub.
- Asegúrate de que tu repositorio incluya todos los elementos solicitados en el desafío, como el código fuente, el README y las evidencias del despliegue.

# Pasos para realizar la entrega

1. Ingresa la URL de tu repositorio de GitHub.
2. Haz clic en Enviar enlace.
3. Selecciona si autorizas o no el uso de tu proyecto con fines pedagógicos y educativos.
4. Una vez completados los pasos anteriores, haz clic en Enviar proyecto para finalizar tu entrega.
