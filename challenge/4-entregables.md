
# Entregables del Challenge Alura Agente

Para completar correctamente el desafío, tu entrega debe incluir los siguientes elementos:

## Repositorio en GitHub

+ Un repositorio público en GitHub con el código fuente de tu proyecto.
+ Un historial de commits que refleje el desarrollo del proyecto.
+ Una estructura organizada y fácil de comprender.

## Documentación (README)

Tu repositorio debe incluir un archivo README que contenga:

+ Una descripción general del proyecto.
+ La arquitectura de la solución implementada.
+ Las tecnologías y herramientas utilizadas.
+ Instrucciones para ejecutar el proyecto.
+ Ejemplos de preguntas que el agente puede responder.
+ Ejemplos de respuestas generadas por el agente.

## Agente Inteligente Funcional

+ Un agente de inteligencia artificial capaz de responder preguntas basadas en el contenido de un documento (PDF o CSV).
+ Código para leer y procesar el documento utilizado como fuente de información.

## ☁️ Evidencia del Deploy en OCI

Debes demostrar que tu aplicación fue desplegada y está funcionando en la nube.

Puedes incluir:

+ El enlace público de la aplicación desplegada.
+ Una captura de pantalla que muestre la aplicación ejecutándose correctamente.
